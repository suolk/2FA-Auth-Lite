# 2FA-Auth-Lite

[English](./README.en.md) | [中文](./README.md)

---

A lightweight TOTP (Time-based One-Time Password) authenticator for two-factor authentication (2FA).

### Overview

2FA-Auth-Lite generates 6-digit verification codes compatible with GitHub, Google, Microsoft, and all platforms supporting TOTP. Available features:

- **Browser Extension** - Quick access from your browser toolbar
- **Import / Export** - Batch export/import as a JSON file
