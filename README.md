# 2FA-Auth-Lite

[English](./README.en.md)

---
轻量级 TOTP（基于时间的一次性密码）身份验证器，用于双因素认证（2FA）。支持扫码添加和批量导入导出json文件

### 概述

2FA-Auth-Lite 生成 6 位验证码，兼容 GitHub、Google、Microsoft 等所有支持 TOTP 的平台。提供以下功能：

- **浏览器扩展** - 从浏览器工具栏快速访问
- **导入导出** - 可批量导出为 JSON 文件
